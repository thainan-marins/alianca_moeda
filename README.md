# Alianças Moedas Bauru

Landing page institucional em Next.js, focada em apresentar as alianças e gerar conversas pelo WhatsApp.

## Rodar localmente

```bash
npm install
npm run dev
```

Abra `http://localhost:3000`.

## Antes de publicar

Confirme endereço, horário, preços, prazo, garantia, políticas, fotos de produtos e dados empresariais. A landing não possui checkout nem captura de dados em servidor; o formulário abre uma conversa no WhatsApp.
