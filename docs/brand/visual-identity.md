# Identidade visual

## Conceito

Joalheria artesanal contemporânea: elegante, próxima e sem a distância de uma marca de luxo inacessível.

## Tokens

- Grafite `#161514` para profundidade e confiança.
- Ouro envelhecido `#cda865` para destaque e calor.
- Marfim `#f7f3eb` para leveza.
- Cobre `#7d5132` como acento material.
- Fonte de exibição: Georgia; interface: Arial/system sans-serif.

## Regras

As referências em `references/insight/` orientam contraste, ritmo editorial, cards e fotografia quente. Não copiar logotipos, conteúdo, produtos, números ou layouts. O logo AMB fornecido é o único ativo de marca utilizado.
