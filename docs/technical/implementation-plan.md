# Plano de implementação

Next.js App Router com TypeScript e CSS próprio, sem banco de dados ou serviços externos. O formulário monta uma mensagem e abre o WhatsApp; assim, nenhum dado é armazenado pelo site na v1.

Critérios de aceite: build e tipos passam, navegação por teclado funciona, contraste e foco são visíveis, página é responsiva, links de conversão funcionam e metadata técnica existe.
