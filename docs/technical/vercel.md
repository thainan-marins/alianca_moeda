# Vercel

## Ambientes

Não há variáveis de ambiente na v1. Preview deve validar links de WhatsApp, desempenho e conteúdo no celular.

## Publicação e rollback

Conectar o repositório à Vercel, validar uma URL de preview e só então promover para produção após aprovação dos dados pendentes. Para rollback, promover o último deployment estável na Vercel.
